RootDock

Dê dois cliques numa sessão à esquerda, use a conexão rápida no topo ou abra um terminal local.

Ctrl+Shift+TNovo terminal local
Ctrl+Shift+KConexão rápida
Ctrl+Shift+D / EDividir a tela
Arrastar uma aba para o terminalJuntar sessões na mesma tela (solte numa borda)
Alt+SetasMudar de painel
Ctrl+TabPróxima aba
Ctrl+Shift+WFechar painel (ou o × no cabeçalho dele)
Ctrl+↑ / ↓Comando anterior / próximo no histórico
Ctrl+Shift+FBuscar no terminal
Ctrl+Shift+SPrint do código (imagem bonita da seleção)
Ctrl+Shift+LBiblioteca de comandos
Ctrl+Shift+HHistórico: buscar comandos de todas as sessões
Selecionar / botão direitoCopiar / colar
Ctrl+= / - / 0Tamanho da fonte
Arquivos: dois cliques num arquivoEditar no RootDock (Ctrl+S salva no servidor)
Dica: arraste uma aba para dentro do terminal e solte perto de uma borda. Arraste o cabeçalho de um painel para trocá-lo de lugar, ou para a barra de abas para separá-lo.
